# GLP-1 Trial Watch

Tracking repository for the endocrinology group's quarterly pipeline review of **GLP-1 receptor agonists in type 2 diabetes**.

## Purpose

This repo captures the late-stage landscape of currently recruiting GLP-1 receptor agonist trials in adults with type 2 diabetes, so the team has a durable, versioned record instead of notes that live in individual inboxes.

## Contents

- **Tracking issues** — one per selected trial (NCT ID in the title; sponsor, phase, planned enrollment, and primary completion date in the body), plus a parent summary issue tying them together.
- **Analysis comments** — per-quarter breakdowns of the recruiting GLP-1 RA / T2D search by phase and by sponsor class.
